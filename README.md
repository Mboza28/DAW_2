# 💻 2º DAW - Desarrollo de Aplicaciones Web

Repositorio principal con los apuntes, ejercicios y proyectos del segundo año del Grado Superior en Desarrollo de Aplicaciones Web.

## Estructura del repositorio

*   **Entorno Cliente:** Apuntes y prácticas de JavaScript moderno (ES6+), manipulación del DOM, asincronía y consumo de APIs.
*   **Entorno Servidor:** Proyectos backend y APIs (node.js, express, conexión a bases de datos).
*   **Despliegue de Aplicaciones Web:** Configuración de servidores, contenedores docker y automatización.
*   **Diseño de Interfaces Web:** Maquetación avanzada, apuntes y animaciones.

## Stack Tecnológico
*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla y frameworks(React / Vue)).
*   **Backend:** Node.js, express.
*   **Bases de Datos:** MySQL / SQL / Mongo DB
*   **Herramientas:** Git, GitHub, Linux, Docker, VS Code.
