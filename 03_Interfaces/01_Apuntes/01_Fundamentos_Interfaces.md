# Fundamentos de interfaces

Una **i**nterfaz** es información que le llega al usuario, en el caso de un videojuego, por ejemplo, es información sobre el personaje, armas, esto se integra con el videojuego pero una interfaz pura es por ejemplo, un menú del videojuego. 
Las interfaces están orientadas puramente al usuario y se crean con la idea de mejorar la experiencia y accesibilidad.

**Definicion**: Una interfaz de usuario es el conjunto de elementos mediante los cuales una persona puede interactuar con un sistema y recibir informacion de él. 
Dicho de forma sencilla: la interfaz es el intermediario entre el usuario y el sistema. Facilitando la comprensión del estado del sistema o de su uso.


---

## 1. Flujo de interacción

*   El usuario interactúa con el sistema a través de la interfaz.
*   El sistema aplica los cambios que sean necesarios.
*   El sistema muestra en la interfaz los cambios realizados para que el usuario pueda verlos.

---

## 2. UI - User Interface

La interfaz de usuario se refiere principalmente a cómo está construida y presentada la interfaz.

Incluye colores, botones, tipografías, iconos, imágenes, menús, formularios, tarjetas, animaciones, distribución de elementos....

Ayuda a la inmersión dentro del juego o página web y sea mas amigable para el usuario.

## 3. UX - User Experience

La UX es la experiencia de usuario que tiene que ver con cómo se siente y qué experimenta el usuario al utilizar un producto o sistema.

*   ¿He entendido qué tengo que hacer?
*   ¿Ha sido fácil?¿Me he perdido?
*   ¿He podido conseguir mi objetivo utilizando el sistema?
*   ¿He cometido errores?
*   ¿La aplicación me facilita volver atrás?

---

## 4. UX != UI

Una web puede ser visualmente buena y sin embargo ofrecer una experiencia de usuario complicada. O por el contrario puede ser visualmente muy sencilla y resultar muy fácil de utilizar.

UX y UI están estrechamente relacionadas pero no significan lo mismo.

No podemos determinar la calidad de una interfaz únicamente por su apariencia. Una interfaz debe responder a las necesidades del usuario y al objetivo del producto.
